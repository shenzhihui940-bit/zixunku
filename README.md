## 打开方式（重要）

**推荐：双击 `打开资讯库.command`**（macOS）。它会在本机 8765 端口起一个静态服务器，并用默认浏览器打开 `http://127.0.0.1:8765/index.html`。走 http 打开不会遇到 file:// 的限制，怎么开都稳。
- 第一次双击如果 macOS 提示「无法验证开发者」：右键 →「打开」→ 确认一次就行。终端里也可以 `bash 打开资讯库.command`。
- **别只依赖双击 html**。Edge、Tabbit 等浏览器在 file:// 下常常拦掉子资源。
- 兜底：封面已经在构建时压缩，并以 base64 data URL（`cover_data` 字段）内嵌进 `index.html`。就算直接双击 html，或者只拷这一个 html 文件，也能看到封面。只有没内嵌的条目才会回退到 `./covers/` 相对路径。

- 外链：每张卡的**封面、标题、域名、「打开原站 ↗」按钮**都是指向原站的链接，点卡片空白处也会打开原站（选中文字时不触发）。
- 若某些 file:// 场景下新标签页被拦，可右键链接「在新标签页打开」或把文件夹放到任意静态服务器（如 `python3 -m http.server`）里打开。
- 手机浏览器也能看。
- 顶栏一级 / 二级分类状态写在 URL hash（如 `#作品集/AI设计作品集`），刷新会回到原位。

## 文件

| 文件 | 作用 |
|------|------|
| `data.json` | 素材条目（唯一数据源） |
| `insights.json` | 可选归档；页面不再展示结论区，build 也不再内嵌 |
| `index.html` | 页面；内嵌 data.json 副本（由 build.py 写入，勿手改数据块） |
| `build.py` | 校验 + 把两个 JSON 重新嵌进 index.html；同时把每条 `cover` 压缩（长边≤800、q65）转成 `cover_data` data URL 内嵌（data.json 不变） |
| `打开资讯库.command` | macOS 一键打开（本地 http 服务 + 浏览器） |
| `covers/` | 卡片封面图（`{id}.jpg`），被 data.json 的 `cover` 字段引用 |
| `preview-tab-*.png` | 各一级分类桌面预览截图（1280 宽） |
| `preview-note-*.png` | 标签选择面板 / 我的笔记本 / 空状态 / 手动精选表单 / 手机版笔记本预览（演示标记只在临时浏览器里，不随站点发布） |
| （浏览器 localStorage） | 个人标记与手动精选，见下文；不写进仓库 |

数据来源：`/workspace/shen/资讯/*.md`（只读）。

## 两级分类（一级 tab / 二级 category）

页面是目录式浏览：**一级 → 二级**，不是混在一起的筛选条。

| 一级 `tab`（顺序固定） | 二级 `category`（只展示有条目的） |
|------------------------|-----------------------------------|
| 个人精选（本机） | 无二级；来自「有用」标记 + 手动外链，不进 data.json |
| 我的笔记本（本机） | 无二级；把所有「有用」按固定标签归类成清单，可导出 Markdown |
| 简历 | AI产品设计简历 / 产品设计简历 / 设计工程师简历 / 简历指南 |
| 作品集 | AI设计作品集 / 产品设计作品集 / 设计工程师作品集 / 作品集指南 |
| 招聘信息 | 岗位趋势 / 招聘信号 / 观点 |
| 作品集简历合集 | 国外目录站 / 国内目录站 / 开源GitHub / 媒体社区 |

- 每条 `data.json` **必须**有 `tab` + `category`，且 `category` 必须属于该 `tab`。
- `insights.json` 可保留作归档，页面与 build 不再使用。
- 平台等三级筛选只在当前一级/二级范围内出现，且计数为 0 的不显示。

## 每轮收集后追加（一条命令）

1. 新资讯照常写成 `/workspace/shen/资讯/YYYY-MM-DD-xxx.md`（URL 必须先出现在笔记里）。
2. 在 `data.json` 数组末尾追加条目，`id` 接着最大编号往后（如 `s097`）：

```json
{
  "id": "s097",
  "title": "标题",
  "url": "https://…（必须是笔记里已有的 URL）",
  "platform": "个人站",
  "track": "AI设计",
  "type": "作品集示例",
  "tab": "作品集",
  "category": "AI设计作品集",
  "verified": "已核",
  "why": "一句中文：设计角度值得看什么",
  "tags": ["信任与失败态", "互动架构"],
  "added": "2026-10-20",
  "source_note": "2026-10-20-xxx.md",
  "cover": "covers/s097.jpg"
}
```

   - **`tab`（必填，一级）**：简历 / 作品集 / 招聘信息 / 作品集简历合集
   - **`category`（必填，二级）**：必须是上表中属于该 `tab` 的值之一
   - `platform`：个人站 / Behance / Dribbble / YouTube / X / 文章 / 目录站 / 指南
   - `track`：设计工程师 / 产品设计 / AI设计 / 通用（遗留字段，卡片不再当主分类）
   - `type`：作品集示例 / 指南文章 / 招聘信号 / 观点 / 目录（遗留字段）
   - `verified`：已核 / 未核链（笔记没写已核的，一律填未核链）
   - `tags` 尽量复用现有标签：信任与失败态、互动架构、定位句、可运行、简历写法、设计转产品、案例骨架、设计系统、Agent工作流、指标叙事、作品集可信度、招聘方视角、反模式、目录线索、中文
   - `source_note` 多份笔记用全角分号 `；` 连接
   - 同一 URL 已存在时不要新增，改原条目的 `why` / `tags` / `source_note` / `tab` / `category` 即可
   - `cover`（**可选**）：封面路径，相对 site 目录。不填或文件缺失时页面显示纯色占位 + 平台首字；build.py 对缺失文件只打印 `!` 警告，不报错
   - 卡片脚注会显示「来源平台：`platform`」「收录笔记：主笔记（去掉年份）+ 等 N 篇」，悬停可看完整笔记列表

### 给新条目做封面（可选）

优先取原站 `og:image` / `twitter:image`；拿不到（X、Behance 等易拦站、纯 JS 站）就用 Pillow 生成占位图（底色按平台/赛道、标题 + 域名）。YouTube 可用 `https://i.ytimg.com/vi/<视频ID>/hqdefault.jpg`。统一转 JPG：长边 ≤1200、quality≈75、单张 <200KB，存成 `covers/{id}.jpg`，再在条目里填 `"cover": "covers/{id}.jpg"`。
3. （可选）`insights.json` 仅作归档，改了也不会进页面。
4. 运行：

```bash
cd /workspace/shen/资讯/site && python3 build.py
```

build.py 会校验：必填字段（含 `tab` / `category`）、枚举值、`category` 归属、日期格式、id/URL 去重、**URL 必须出现在 `资讯/*.md` 某份笔记中**、source_note 文件存在。任何一项不过就报错退出，不改 index.html。通过后打印条目数（按一级）、未核链数。

页面顶部的条目总数、最后更新日期（取 `added` 最大值）、一二级选项与计数都根据数据自动生成，不用手改。


## 个人标记、「个人精选」与「我的笔记本」（本机 localStorage）

页面支持在卡片上直接标记，**不改 data.json**，只写在打开该站的浏览器里：

| localStorage key | 内容 |
|------------------|------|
| `zixunku.marks.v1` | 按条目 `id` 存标记：有用 → `{ mark: "useful", tags: string[], note: string, at: ISO }`；不看了 → `{ mark: "skip", at: ISO }` |
| `zixunku.manualPicks.v1` | 手动外部精选数组：`[{ id, title, url, note, tags: string[], source, added }]` |

- **只有两个按钮：「有用」「不看了」**。旧版的「一般」（`ok`）在页面加载时自动迁移为未标记（直接删掉该条）；旧的有用条目会补上 `tags: []`，备注保留。
- 点「有用」→ 卡片里展开小面板：**固定标签多选**（不能自由输入标签）+ 可选一行备注 →「保存」；「稍后再选」= 先标有用、不选标签。
- 已有用的卡：再点「有用 ✓」、点角标「有用 · N」或「编辑标签」都能重新编辑；面板里「取消「有用」」可撤销。改成「不看了」会清掉标签和备注。面板里 Enter 保存、Esc 关闭。
- 「有用」卡片有浅绿描边，标签以小胶囊显示在卡片底部；「不看了」变淡；库内 tab 仍有「只看未标记」「隐藏不看了」。

### 固定标签（按条目的一级 tab）

| 适用 | 分组 · 标签 |
|------|------------|
| 作品集 / 作品集简历合集 / 简历 / 手动精选 | 视觉：版式、质感、动效、配色、字体 · 内容：故事怎么讲、案例够不够深、有没有结果数字 · 架构：信息怎么排、交互怎么走、设计系统 · 岗位相关：有AI产品感、说清人机边界、有可点开的Demo |
| 招聘信息（= 看完怎么用到简历/作品集） | 简历/作品集要写进去、别再这么写了、面试官在看什么、岗位要求变了、这句话能直接用 |

改标签集合：只改 `index.html` 脚本里的 `TAGSET_PORTFOLIO` / `TAGSET_JOB`（笔记本分组 `NB_GROUPS` 跟着前者走）。加载时会把旧标签文案映射成新白话名（`TAG_RENAME`），已有标记继续可用。

### 一级 tab

- **个人精选**（最前）：所有「有用」的库内条目 + 手动添加的外部链接，卡片形式。手动添加表单：标题、链接、备注、来源 + 同一套作品集固定标签。
- **我的笔记本**（紧跟个人精选）：把所有「有用」压成一行一条的清单（标题→新标签页打开原站、备注、来源 tab、标记日期、「改标签」跳到原卡片并打开面板）。顺序：
  1. 高亮区「简历/作品集要写进去」（绿）「别再这么写了」（红）（并排）→「这句话能直接用」（蓝）
  2. 作品集分组：视觉 / 内容 / 架构 / 岗位相关（按标签细分，空标签不显示）
  3. 招聘观察：面试官在看什么 / 岗位要求变了
  4. 「还没选标签」的有用条目
  - 一条选了多个标签会在多处出现。顶部搜索框同样可过滤笔记本。
  - 「导出 Markdown」下载 `我的笔记本-YYYY-MM-DD.md`；「复制」把同样的 Markdown 放进剪贴板（file:// 下自动退回兼容复制）。
  - 空状态会提示怎么填：去卡片点「有用」+ 选标签。
- **每日收集流程不变**：笔记 → 追加 `data.json` → `python3 build.py`。标记、标签、笔记本只在本机，换浏览器或清站点数据会丢，v1 不上传；需要留档就定期「导出 Markdown」。
